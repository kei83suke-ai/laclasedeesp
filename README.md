# スペイン語学習アプリ

2026年10月13日、新規版Excelの辞書を取り込んだアップロード用一式です。ビルド作業や外部データベースの契約は不要です。

## 最初にすること

同じフォルダーの「GitHubアップロード手順.md」を開いてください。GitHubへは、このフォルダーの**中身をまとめて**アップロードします。ExcelやZIPそのものを置くのではありません。

## 収録内容

- 29,813見出し語。英語訳・日本語訳を全件収録。
- 動詞2,972語のうち、2,971語に活用あり（部分登録を含む）。活用形は109,812件。
- tar は活用未登録、culiar の12枠は未確認のため保留。
- acontecer は三人称専用、cilampear は非人称、munir は確認できた過去分詞だけを収録。空欄を推測で補っていません。
- CEFRは元データにある値だけを使用し、未登録は空欄扱い。
- 例文・動詞フレーズを追加していません。

## 訳語の確認状況

登録が終わったことと、全件の正確性監査が終わったことは異なります。

- 機械翻訳・未監査：21,767語。
- AI照合した新規訳：2,386語（うち127語は要確認事項あり）。
- 全件のRAE照合や、英日すべての語義の対照は未完了です。
- すべて検索・カードで閲覧できます。未照合の辞書訳、機械翻訳、明示的な要確認訳はクイズに出しません。既存訳の出題方針は維持しています。

## ファイルの役割

| ファイル・フォルダー | 役割 |
| --- | --- |
| `index.html` | アプリの入口。32個の辞書ファイルもここから順に読み込みます。 |
| `js/data.js` | 辞書の初期設定、動詞ID一覧、収録数と出典情報。 |
| `js/dictionary/` | 全単語・訳・活用の実データ。フォルダーごと必要です。 |
| `js/app.js` | 画面とクイズ。訳語の確認状態による出題制限を含みます。 |
| `js/learning.js` | 学習履歴・復習管理。今回、内容は変更していません。 |
| `css/style.css` | 画面の見た目。今回、内容は変更していません。 |
| `sw.js` | 端末内へのオフライン保存と辞書更新。 |
| `data/` | 取り込み件数・出典・確認結果。 |
| `tools/` と `test.js` | 次回のデータ更新・検証用。通常利用時の操作は不要です。 |

今回のデータは32ファイルに分割してあります。`js/data.js` だけを交換しても完成しません。`index.html`、`js` フォルダー、`sw.js` などを一式で更新してください。

## 学習履歴とオフライン

単語IDと既存の旧ID対応を保持しています。同じブラウザー・同じサイトのアドレスで更新し、サイトの保存データを消さなければ、既存履歴を引き継ぐ設計です。公開URL・端末・ブラウザーを変えた場合の履歴移行は別作業です。アップロード用ファイルには、個人の学習履歴は含めていません。

公開後、オンラインでアプリを開いて読み込み完了を待ち、いったん閉じて再び開いてください。単語カードの「辞書の出典・確認状況」で更新日を確認し、機内モードでも開けることを確認してください。端末の空き容量やブラウザーによるデータ削除で再ダウンロードが必要になる場合があります。音声のオフライン利用は端末に利用可能な音声があるかにも依存します。

## 出典とライセンス

辞書本文には Wiktionary contributors のデータを含みます。Kaikki.org / Wiktextract (Tatu Ylonen) の抽出データをもとに、見出し整理・重複統合・日本語訳の関連付け／翻訳・活用の照合を行っています。辞書データは CC BY-SA 4.0 の条件に従って扱ってください。アプリのプログラム全体に一律のライセンスを新たに付与するものではありません。

- [Kaikki.org](https://kaikki.org/)
- [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 頻度：wordfreq (Robyn Speer) およびその元資料。[著作者・条件](https://github.com/rspeer/wordfreq/blob/master/NOTICE.md)
- 各語の出典・ライセンス・確認状態は辞書データ内に残しています。
- RAE / ASALE の参照URLは照合の根拠です。RAEによる全件の保証・監修を意味しません。

## 次回のExcel更新（開発者向け）

元Excelは変更しません。取り込みには Python 3 と openpyxl、Node.js が必要です。通常のアプリ利用・GitHubへのアップロードにはインストール不要です。

1. アプリ全体をバックアップします。
2. アプリとは別の作業フォルダーにExcelから読み出します。
   `python3 tools/extract_workbook.py "新規版.xlsx" "/tmp/workbook.json"`
3. アプリフォルダーで実行します。
   `node tools/build_dictionary.mjs /tmp/workbook.json . . YYYY-MM-DD`
4. `node test.js` と `node tools/verify_import.cjs /tmp/workbook.json` を実行します。件数や語彙を増減した場合、テスト内の版固有の期待値も実データに照らして見直してください。
5. 更新ファイルを同じコミットでアップロードします。

旧版の `import_excel.py` は元の単語帳用です。新規版には使わないでください。新規版のセルが想定外の形式、ID重複、未登録の時制・人称などの場合、取り込み処理は停止します。欠けた訳・活用を自動生成しません。
